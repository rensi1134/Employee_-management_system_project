# Employee_-management_system_project

A simple and efficient Employee Management System built using **Django** and **Python**. The system allows users to **add**, **view**, **edit**, **delete**, and **filter** employee details. It is designed to streamline basic HR operations.

## 🚀 Features

- Add new employee details
- View all employees
- Edit existing employee information
- Delete employee records
- Filter/search employees by name, department, or role

## 🛠️ Tech Stack

- **Backend**: Python, Django
- **Frontend**: HTML, CSS (Bootstrap )
- **Database**: SQLite (default with Django)
